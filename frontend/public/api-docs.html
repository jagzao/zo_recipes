🚀 Quick Start Guide

Welcome to the KitchenEye API documentation. This API powers multi-tenant smart kitchen monitoring with computer vision.

1. Authentication

Create an account and get your JWT token:

POST /api/auth/signup
{
  "email": "you@restaurant.com",
  "tenant_name": "My Restaurant",
  "owner_name": "Your Name"
}

You'll receive a JWT token in the response. Use it in the Authorization header:

Authorization: Bearer YOUR_JWT_TOKEN

2. Try It Out

Use the interactive documentation below to test endpoints. Click "Authorize" and enter your JWT token.

Base URL:

https://your-worker.workers.dev

3. Rate Limits

API requests are rate-limited:

  • IP: 100 requests/minute
  • Tenant: 1000 requests/hour
  • Camera: 60 requests/minute

4. Edge Device Integration

For edge CV devices, use HMAC authentication:

import hmac, hashlib, json

signature = hmac.new(
  secret.encode(),
  json.dumps(payload).encode(),
  hashlib.sha256
).hexdigest()

headers = {
  'X-Signature': signature
}
